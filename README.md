# Strikers - a native PC port of Super Mario Strikers 

- Support for high framerates, ultrawide
- xInput support
- Enhanced rendering
- Fast load-times compared to original hardware

Tested on: an Intel N100 system, Raspberry Pi 5 and developed on a modern MacBook Pro. 
I don’t have my Steam Deck with me right now but I will be releasing for optimal power draw and performance so it sips battery, as well for best gameplay experience.
